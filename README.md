# Первые 100 дней

Веб-приложение программы очной подготовки к самостоятельной жизни и сопровождения выпускников детских домов. Кирилл Проконов и Степан Филиппов, УлГТУ.

## Telegram-бот

В папке [telegram-bot](telegram-bot/README.md) находится бот регистрации участников и работодателей. Он принимает обращения, публикует вакансии после проверки координатором, передаёт отклики и сообщает о решениях. Бот запускается из исходников на Python 3.11+, данные и черновики сохраняются в SQLite.

```powershell
cd telegram-bot
python main.py
```

Перед запуском заполните локальный `.env` по примеру `.env.example`. Подробные инструкции, сценарий демонстрации, настройки координаторов и Docker Compose описаны в [README бота](telegram-bot/README.md).

## Разработка

Нужны Node.js 22.12+ в ветке 22, npm, JDK 17+ и Maven 3.6.3+. Выполняйте команды из корня репозитория.

Запустите Spring Boot в первом терминале.

```powershell
mvn -f backend/pom.xml spring-boot:run
```

Запустите React во втором терминале.

```powershell
npm --prefix frontend ci
npm --prefix frontend run dev
```

Откройте http://127.0.0.1:5173. Vite перенаправляет запросы к `/api` на Spring Boot по адресу http://127.0.0.1:8080. Файлы интерфейса лежат в `frontend/src/`, серверный код и учебные материалы — в `backend/src/main/`.

## Vercel

Импортируйте GitHub-репозиторий в Vercel, выберите корень репозитория и пресет **Container**. `Dockerfile.vercel` собирает React и Spring Boot из исходников. Команды сборки заданы в Dockerfile, отдельные настройки Build Command и Output Directory не нужны. Приложение и API доступны на одном домене.

Чтобы опубликовать согласованный адрес команды, задайте переменную `PROGRAM_CONTACT_EMAIL` в настройках проекта Vercel или перед локальным запуском Spring Boot. Без неё в разделе «Контакты» доступны контакты действующих служб.

## Как показать проект

1. Откройте «О программе». Покажите четыре очных занятия и встречи на 1-й, 14-й, 30-й, 60-й и 100-й дни после выпуска.
2. Откройте «Маршрут к работе». Покажите учебную вакансию и пример отклика, затем отметьте готовое резюме. Приложение покажет следующий шаг.
3. Переключите день встречи на 30-й. Обсудите, как специалист поможет при задержке первого шага.
4. В «Материалах» скачайте один из шаблонов. В «Контактах» покажите, куда выпускник может обратиться сейчас.

Маршрут демонстрационный. Отметки о выполненных шагах хранятся до восьми часов в cookie браузера. В приложении нет анкет участников. Учреждение, специалисты и контакт проекта для первого запуска ещё согласовываются. На защиту вынесены программа и интерактивный маршрут на примере первой работы.

## Устройство

- `frontend/` — React и Vite. Шрифт Inter упаковывается локально.
- `backend/` — Spring Boot. API выдаёт каталог и файлы, сохраняет отметки маршрута в cookie. При развёртывании Spring Boot также отдаёт собранный React.
- `GET /api/program`, `GET /api/materials/{id}/download`, `GET /api/progress`, `PUT /api/progress`.
