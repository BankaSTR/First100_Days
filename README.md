# Первые 100 дней

Веб-приложение программы очной подготовки к самостоятельной жизни и сопровождения выпускников детских домов. Кирилл Проконов и Степан Филиппов, УлГТУ.

## Запуск

Нужны Node.js 22.12 или новее в ветке 22, npm, JDK 17+ и Maven 3.6.3+. Установка зависимостей при первой сборке требует интернета.

```powershell
npm --prefix frontend ci
npm --prefix frontend run build
mvn -f backend/pom.xml clean package
java -jar backend/target/first100-days-1.0.0.jar
```

Откройте http://127.0.0.1:8080. После сборки JAR содержит интерфейс, шрифты, изображение, материалы и API. Для показа достаточно Java, готового JAR и браузера. Внешние ссылки на службы требуют подключения к интернету.

Для разработки запустите `mvn -f backend/pom.xml spring-boot:run` и `npm --prefix frontend run dev` в разных терминалах. Vite перенаправляет запросы `/api` на Spring Boot. Если порт занят, готовый JAR можно запустить с аргументом `--server.port=8081`.

Чтобы опубликовать согласованный адрес проекта в разделе «Контакты», перед запуском задайте `PROGRAM_CONTACT_EMAIL`. Без него посетителям доступны контакты действующих служб.

## Как показать проект

1. Откройте «О программе». Покажите четыре очных занятия и встречи на 1-й, 14-й, 30-й, 60-й и 100-й дни после выпуска.
2. Откройте «Маршрут к работе». Покажите учебную вакансию и пример отклика, затем отметьте готовое резюме. Приложение покажет следующий шаг.
3. Переключите день встречи на 30-й. Обсудите, как специалист поможет при задержке первого шага.
4. В «Материалах» скачайте один из шаблонов. В «Контактах» покажите, куда выпускник может обратиться сейчас.

Маршрут демонстрационный. Spring Boot хранит только отметки о выполненных шагах в сессии браузера, до её истечения или перезапуска сервера. В приложении нет анкет участников. Учреждение, специалисты и контакт проекта для реального пилота ещё согласовываются. На защиту вынесены программа и интерактивный маршрут на примере первой работы.

Основное предложение для пилота — провести четыре очных занятия и в течение 100 дней проверять продвижение по цели, которую выбрал участник. Предварительная смета из дорожной карты — 32 600 ₽ на группу из десяти человек.

## Устройство

- `frontend/` — React и Vite. Шрифты PT Serif и Inter упаковываются локально.
- `backend/` — Spring Boot. API выдаёт каталог и файлы, сохраняет отметки маршрута в сессии. Готовый фронтенд упаковывается в JAR.
- `GET /api/program`, `GET /api/materials/{id}/download`, `GET /api/progress`, `PUT /api/progress`.

Фото на главной — иллюстрация, созданная встроенным ImageGen. Промпт: документальная фотография очного занятия, молодой взрослый и специалист разбирают лист задания за деревянным столом в светлой аудитории, мягкий дневной свет, лица за кадром, без надписей.
